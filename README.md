# Ethical Real Estate Data Parser & EDA Pipeline

This project is the first module (Data Collection & Data Engineering) of a larger MLOps ecosystem aimed at predicting real estate prices in Prague. 

**Note:** For ethical reasons and compliance with Terms of Service, the scraped raw datasets (`*.csv`) are strictly ignored via `.gitignore` and are not published in this repository. Only the generated statistical metadata (`*_metadata.json`) is committed as proof of concept.

## Features
* **Custom Scraper:** Extracts real estate listings (rent and sale) directly into structured data.
* **Robust EDA Cleaner:** 
  * Implements IQR (Interquartile Range) algorithms for outlier detection and removal.
  * Dynamically handles missing values and maps ordinal text features.
  * Automatically switches parsing logic between 'Rental' and 'Sale' specific columns (e.g., Furnished vs. Material).
* **Metadata Generation:** Compiles cleaned data distributions into JSON configurations, designed to feed dynamic UI dropdowns for the frontend application.

## Repository Structure
* `parser.py` — The data extraction engine.
* `eda_cleaner.py` — The core Data Engineering and cleaning script.
* `main.py` — The orchestrator that runs the full pipeline from extraction to metadata generation.
* `*_metadata.json` — Aggregated statistical outputs (min/max ranges, valid categories) generated by the cleaner.

## Tech Stack
* Python 3
* Pandas
* Natsort (for natural sorting of Czech districts)
