# Ethical Real Estate Data Parser & EDA Pipeline

This project is the first module (Data Extraction & Data Engineering) of a larger MLOps ecosystem aimed at predicting real estate prices in Prague. 

**Note on Ethical Data Usage:** To strictly comply with Terms of Service and anti-scraping policies, no automated web crawlers were used against live servers. Raw API responses were collected manually in batched JSON files. Furthermore, to respect data copyright, all raw JSON batches and resulting `*.csv` datasets are ignored via `.gitignore` and are not published. Only the data processing code and aggregated statistical metadata (`*_metadata.json`) are committed as proof of concept.

## Features
* **Custom  Local JSON Extractor (`parser.py`):** 
  * **Directory-based Feature Engineering:** Automatically infers implicit property attributes (Condition, Furnished/Material status) from the hierarchical folder structure (e.g., parsing files inside `dataset/pronajem/velmi_dobry/vybavena/`).
  * **Deep JSON Traversal:** Flattens complex, deeply nested React/Next.js states (`dehydratedState`) into structured tabular records.
  * **Smart Deduplication:** Implements a signature-based hashing mechanism `(type, locality, district, area, price)` to ensure zero data duplication across overlapping JSON chunks.
  * **Dynamic Mapping:** Uses a constant map to translate Czech category slugs directly into standardized English labels during the extraction phase.
* **Robust EDA Cleaner (`eda_cleaner.py`):** 
  * Implements IQR (Interquartile Range) algorithms for outlier detection and removal.
  * Dynamically handles missing values and maps ordinal text features.
  * Automatically switches parsing logic between 'Rental' and 'Sale' specific columns (e.g., Furnished vs. Material).
* **Metadata Generation:** Compiles cleaned data distributions into JSON configurations, designed to feed dynamic UI dropdowns for the frontend application.

## Repository Structure
* `dataset/` — (Ignored) Local directory containing manually downloaded JSON batches and compiled CSVs.
* `parser.py` — The data extraction engine that processes local JSON chunks.
* `eda_cleaner.py` — The core Data Engineering and cleaning script.
* `main.py` — The orchestrator that runs the full pipeline from JSON extraction to metadata generation.
* `*_metadata.json` — Aggregated statistical outputs (min/max ranges, valid categories) generated by the cleaner.
